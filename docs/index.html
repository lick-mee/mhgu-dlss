Install it

Four steps, no tools to install. Tick each one off as you go; the folder on the right shows what should be next to the game by then.

  1. Download the zip

    From the repository's Releases: mhgu-dlss-v1.0.0.zip.

    Open Releases

  2. Extract it next to mhgurecomp.exe

    Into the game's own folder, not into mods. Two DLLs, a short readme and this guide's folder land there.

  3. Add NVIDIA's DLLs

    nvngx_dlss.dll for DLAA, and nvngx_dlssnr.dll if you want neural rendering. They're NVIDIA's files and aren't in the zip; put them in the same folder.

  4. Start the game

    Nothing changes yet: everything starts switched off. You turn it on in the Forge menu, shown below.

Nothing to restart

        
Every switch takes effect on the next frame, and every change is saved right away. Delete the [DLSS] lines in mhgurecomp.ini to start over with everything off.

      

      

        
When something's missing

        
The menu says so if DLSS can't run. mhgu-dlss.log next to the game lists what was found and what failed, such as a missing nvngx_dlss.dll.

      

      

        
Uninstall

        
Delete vulkan-1.dll and mhgudlss_nvngx.dll. The game runs as before; the settings in the ini are ignored.
